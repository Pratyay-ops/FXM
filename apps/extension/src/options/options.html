FXM Connect

Version Development build

FXM Connect only lets the FXM web app reach music services (YouTube, Spotify and Last.fm) from your own browser. It adds the headers those services need to answer FXM, fetches Spotify's public server time for it and, only if you turn on the Spotify setting below, gets a Spotify token for your own Spotify login. It has no analytics or tracking and runs no remote code.

Development build. It treats any app served on the localhost origins listed below as FXM, including other projects and their dependencies. Keep the Spotify login off for localhost, or use a separate browser profile for development. Never publish this build.

Spotify

Off by default. When on, the FXM app can ask FXM Connect for a Spotify access token for the account you are signed in to at open.spotify.com in this browser. The app asks for one only after you also connect your Spotify account in FXM. FXM Connect fetches the token from open.spotify.com with your browser's existing Spotify session and passes FXM only the token response. It never reads, stores or shares your cookies. Spotify's terms don't permit automated access like FXM's, and they let Spotify suspend accounts that break them; no such case has been reported for this kind of use.

When you turn this on, Firefox asks you to let FXM Connect "share authentication information with extension developer", because the token is your Spotify login. Here that means the FXM web app in this browser, which uses the token only for its requests to Spotify; no FXM server receives it. If you withdraw the consent in Firefox's add-on settings, FXM can no longer use your login.

Development build only, off by default, and only in effect while the setting above is on. Any app on the localhost origins below could then get a token for your Spotify account.
