FXM Connect

Version Development build

FXM Connect only lets the FXM web app reach music services (YouTube, Spotify and Last.fm) from your own browser. It adds the headers those services need to answer FXM, contains no YouTube or Spotify logic, collects no data and runs no remote code.

Development build. It treats any app served on the localhost origins listed below as FXM, including other projects and their dependencies. Keep the Spotify login off for localhost, or use a separate browser profile for development. Never publish this build.

Spotify

Off by default. When on, the FXM app can ask FXM Connect for a Spotify access token for the account you are signed in to at open.spotify.com in this browser. FXM Connect fetches the token from open.spotify.com with your browser's existing Spotify session and passes FXM only the token response. It never reads, stores or shares your cookies.

Development build only, off by default, and only in effect while the setting above is on. Any app on the localhost origins below could then get a token for your Spotify account.
